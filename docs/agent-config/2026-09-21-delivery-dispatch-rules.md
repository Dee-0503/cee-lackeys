# 交付与派活规则：2026-09-21.5

修复 Iris 只承诺“会交付组织图和工作流图”却没有创建文档、看板或日历记录的问题。

所有 Agent 的核心系统提示词现在要求：

- 要求报告、图表、文档、研究结果等可见产物时，同一轮产生可核验副作用：创建／更新 Cumora 文档、Kanban 卡片、Calendar 复查事件，或报告真实阻塞。
- 最终交付必须返回产物链接、任务 ID 或具体失败证据，不能只说“我会整理”。
- 短问题、补充说明、一次性确认使用私聊。
- 有负责人、交付物、阶段、持续时间或需要跟踪的工作，优先用 Kanban 作为主记录。
- 指定时间唤醒或提醒使用 Calendar。
- 可以 Kanban 主记录加私聊补充上下文，但私聊不能成为唯一长期状态。

版本已部署到 Cumora 的九个 Agent。规则不创建任务或图表，也不替代真实看板／日历连接的验收。
