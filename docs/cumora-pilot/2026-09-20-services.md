## Rollback

停止现有 pilot：

```sh
ssh cee-server 'sudo docker compose -p cumora-pilot -f /home/cee/apps/cumora-pilot/compose.yaml stop'
```

备份脚本 `sudo bash /home/cee/apps/cumora-pilot/backup.sh` 会停止应用和 Redis 写入，备份后留为停止状态；现有基础服务重新启动用同一项目作用域 `up -d --wait postgres redis`。

恢复必须在独立空恢复目录/项目中，恢复 Postgres dump、Redis AOF/RDB、uploads，并从安全秘密来源恢复 secret；当前仅验证备份生成和 dump 目录可读，尚未验证完整恢复。应用旧镜像回滚须配合匹配 schema 备份。清理必须明确授权后只作用于 pilot 数据及镜像，保留备份，不执行 broad recursive delete/prune。
