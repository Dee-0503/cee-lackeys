### Web UI 配置引导核验

- `server/src/env.ts` 在应用启动时强制要求 OPENAI_API_KEY；生产模式拒绝公开开发版 AGENT_RUNTIME_SECRET。服务器先启动，才能提供 SPA 和 API。
- `src/components/AuthScreen.tsx` 为 OAuth 登录页，不提供本地密码注册或服务器环境变量初始化表单。
- `src/desktop/Onboarding.tsx` 存在首次引导，但它是登录后的 BYOA Computer 配对流程，不能用来补齐启动前密钥或 OAuth。
- 该引导生成 `npx cumora@latest agent computer ...`，还默认选中安装服务；与本试点固定版本、暂不安装 Agent CLI 的边界不符。本轮没有执行这些命令；后续人工验收必须避免直接照抄。
